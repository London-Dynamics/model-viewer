LD USDZ by London Dynamics. Room scans from RoomPlan, Polycam, and Scaniverse are USDZ. convertUsdzToGlb turns them into GLB in the browser, and a src that ends in .usdz (or is served as model/vnd.usdz+zip) does the same before the normal model pipeline.

Drop a USDZ file or paste a URL. Conversion stays on the main thread and loads three's USD parser only when needed.
