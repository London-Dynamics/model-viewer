# Three.js Water Pro

Real-time FFT-based ocean water simulation for Three.js using WebGPU compute shaders.

## Requirements

- Node.js 18+
- WebGPU-compatible browser (Chrome 113+ recommended)

## Demo

```bash
npm install
npm run dev
```

Opens at `http://localhost:3001`

## Build Library

```bash
npm run build:lib
```

Outputs to `dist/`.

## Documentation

Full documentation: https://threejs-water-pro.vercel.app

To view docs locally:

```bash
npm run docs
```

Opens at `http://localhost:5173`

To build docs for static hosting:

```bash
npm run docs:build
```
