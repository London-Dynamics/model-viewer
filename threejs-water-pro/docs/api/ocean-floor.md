# Ocean Floor

Manages the ocean floor mesh with procedural displacement, texture blending, and animated caustics. Blends between sand and rocky textures based on terrain height — elevated areas appear rocky while valleys are sandy.

Access via `water.floor`.

## Properties

| Property   | Type       | Description          |
| ---------- | ---------- | -------------------- |
| `caustics` | `Caustics` | Caustics shader (see [Caustics](#caustics)) |

## Methods

```typescript
getDepth(): number
```

Get the current depth of the floor below the water surface, in world units.

### `getMesh`

### `isVisible`


| Parameter | Type | Description |

| `depth` | `number` | Distance below the surface, in world units. |

### `setVisible`

```typescript
setVisible(visible: boolean): void
```

| Parameter | Type | Description |
| --- | --- | --- |
| `visible` | `boolean` | `true` to show, `false` to hide. |

### `updateCausticsConfig`

```typescript
updateCausticsConfig(config: OceanFloorCaustics): void
```

Update caustics settings at runtime. See [Caustics](#caustics).

| Parameter | Type | Description |
| --- | --- | --- |
| `config` | `OceanFloorCaustics` | Caustics settings to apply. |

### `updateDisplacementConfig`

```typescript
updateDisplacementConfig(config: Partial<OceanFloorOptions>): void
```

Update terrain displacement settings at runtime.

| Parameter | Type | Description |
| --- | --- | --- |
| `config` | `Partial<OceanFloorOptions>` | Displacement-related fields to apply; omitted fields are left unchanged. |

```typescript
water.floor.setDepth(40);
water.floor.setVisible(false);
```

::: tip
To fully recreate the ocean floor with different geometry or textures, use `water.recreateOceanFloor(options)` on the WaterSystem.
:::

## OceanFloorOptions {#options}

Options passed to `water.recreateOceanFloor()`.

| Option                        | Type                  | Default | Description                                          |
| ----------------------------- | --------------------- | ------- | ---------------------------------------------------- |
| `blendSoftness`               | `number`              | `0.3`   | Width of sand/rocky blend transition                 |
| `blendThreshold`              | `number`              | `0.5`   | Terrain height where sand/rocky blend transitions    |
| `caustics`                    | `OceanFloorCaustics`  | —       | Caustics configuration                               |
| `customTextures`              | `CustomTextureConfig` | —       | Custom texture paths                                 |
| `depth`                       | `number`              | —       | **(required)** Initial depth below water             |
| `displacementScale`           | `number`              | `150.0` | Noise feature size (larger = larger terrain features) |
| `displacementStrength`        | `number`              | `5.0`   | Vertical displacement amount                         |
| `lacunarity`                  | `number`              | `2.0`   | FBM frequency multiplier                             |
| `meshResolution`              | `number`              | `32`    | Resolution of mesh geometry                          |
| `normalScale`                 | `number`              | `1.0`   | Normal map strength                                  |
| `persistence`                 | `number`              | `0.5`   | FBM amplitude decay                                  |
| `size`                        | `number`              | —       | **(required)** Size of ocean floor mesh              |
| `textureDisplacementStrength` | `number`              | `0.5`   | Strength of texture-based displacement               |
| `tileSize`                    | `number`              | `400`   | Tile size for texture/caustics                       |

## Caustics {#caustics}

Caustics are generated by sampling a pre-generated seamless Voronoi texture at multiple UV offsets, scales, and scroll speeds. Two independently scrolling layers are combined with `min()` for natural interference patterns. Wave simulation normals distort the UVs so patterns swim in sync with wave motion.

| Option                | Type      | Default | Description                                              |
| --------------------- | --------- | ------- | -------------------------------------------------------- |
| `depthAttenuation`    | `number`  | `0.4`   | Intensity fade with depth (0 = none, 1 = strong)         |
| `enabled`             | `boolean` | —       | Enable/disable caustics                                  |
| `intensity`           | `number`  | `0.61`  | Overall brightness (0–5)                                 |
| `scale`               | `number`  | `65.0`  | World-space tile scale                                   |
| `waveDistortion`      | `number`  | `0.2`   | How strongly wave normals distort the procedural UVs     |

```typescript
water.floor.updateCausticsConfig({
  enabled: true,
  depthAttenuation: 0.4,
  intensity: 0.61,
  scale: 65.0,
  waveDistortion: 0.2,
});
```

## CustomTextureConfig {#custom-textures}

| Option      | Type     | Description              |
| ----------- | -------- | ------------------------ |
| `colorUrl`  | `string` | Path to color texture    |
| `normalUrl` | `string` | Path to normal map       |

## Example

```typescript
// Adjust depth at runtime
water.floor.setDepth(50);

// Update caustics
water.floor.updateCausticsConfig({
  enabled: true,
  depthAttenuation: 0.4,
  intensity: 0.61,
  scale: 65.0,
  waveDistortion: 0.2,
});

// Recreate with different geometry
await water.recreateOceanFloor({
  meshResolution: 64,
  depth: 30,
  displacementStrength: 8.0,
  caustics: {
    enabled: true,
    depthAttenuation: 0.4,
    intensity: 0.61,
    waveDistortion: 0.2,
  },
});
```
